# 赛点｜内部赛事竞猜 MVP

面向 2026–2027 内部策划赛的封闭式虚拟积分竞猜系统。当前版本提供数据库账号会话、赛程盘口、事务化单场与过关竞猜、动态奖池结算、真实钱包账本和运营管理台。

## 规则边界

- 竞猜币与点券均为内部虚拟积分；不可购买、提现、转赠或借贷。
- BO2 支持胜 / 平 / 负，BO3 支持系列赛胜者。
- 最低下注 50，单场不设额外上限，用户最多可押全部可用竞猜币余额。
- 结算按 `25% 本金返还 + 70% 中奖奖池 + 5% 系统回收` 计算。
- 选手不能下注本人或联姻战队的比赛；管理员和记分员不能参与竞猜。

## 本地启动

```bash
npm install
copy .env.example .env
npm run db:generate
npx prisma migrate deploy
npm run db:seed
npm run dev -- --port 3108
```

也可以直接双击 `启动本地竞猜系统.bat`，脚本会自动完成检查并打开 `http://localhost:3108`。

## 局域网服务器

双击 `启动局域网竞猜服务器.bat`，允许 Windows 管理员授权后，脚本会：

- 构建并启动生产服务器，监听 `0.0.0.0:3108`
- 在 Windows 防火墙中仅向当前本地子网开放 TCP 3108 端口
- 在窗口中显示局域网访问地址，例如 `http://192.168.1.20:3108`

其他用户需要与服务器电脑连接同一个局域网，并通过脚本显示的 IP 地址访问。服务器窗口必须保持开启；电脑进入睡眠或切换网络后将无法访问。该方式仅用于可信局域网，不会自动暴露到公网。

默认账号：

- 管理员：`admin / 000000`
- 普通用户：`Demo User / 000000`、`Stellar / 000000`、`River / 000000`
- 新建账号的初始密码为 `000000`。用户可在侧边栏修改密码，管理员可重置密码；改密或重置会注销该用户已有会话。

数据库已完成一次性重建。日常启动只执行 migration 和幂等 seed，不会清空真实下注、钱包或赛程数据。只有明确需要销毁本地数据时才可手动运行 `prisma migrate reset`，禁止对生产数据库执行该命令。

## 数据闭环

- 盘口和封盘时间由 SQLite / Prisma 数据决定；读取盘口和提交下注时，服务端会自动关闭到期盘口。
- 单场下注在事务中完成订单、钱包扣款和账本流水，重复幂等键不会重复扣款。
- 管理员结算必须选择获胜选项并录入比分；退款、返还和奖励均生成可关联订单的账本流水。
- 首位用户购买过关后，数据库冻结场次、门票、奖池和最早封盘时间；结果齐全后自动判定和派奖。
- Cookie 会话为 httpOnly，所有资产、下注和管理员接口均在服务端验证用户与角色。

## 主要目录

- `prisma/schema.prisma`：账号会话、赛事、单场/过关订单、钱包、账本、结算与审计模型
- `prisma/seed.ts`：24 支临时 A/B 战队、4 个默认账号、第 1–4 周赛程和可核对订单
- `src/lib/settlement.ts`：动态奖池、限额和利益冲突规则
- `src/lib/services`：盘口封盘、下注事务、结算与过关服务
- `src/lib/auth`：密码哈希与数据库会话
- `src/app/api`：会话、盘口、订单、钱包、过关和管理员 API
- `src/components/dashboard.tsx`：竞猜大厅、排行榜与管理工作台
- `src/components/my-bets-panel.tsx`：真实单场和过关订单
- `src/components/wallet-panel.tsx`：真实余额与账本流水
